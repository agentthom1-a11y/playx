# Changelog

## 0.3.0b1 — Local Studio public-beta candidate

- Browser upload/drop zones, waveform preview, background job queue, progress, WAV playback/download and QA JSON.
- Security: loopback Host/Origin checks, file type/size/duration constraints, opaque job IDs, safe export paths, overwrite prevention.
- Streaming signal-level quality checks, improved drop-swap ramp and atomic render handling.
- Setlist harmonic/BPM/energy heuristic and experimental 2–6 track setmix command.
- Windows portable PyInstaller workflow, CMD bootstrap, CI OS/Python matrix and commercial release gates.

## 0.2.0 — Mixxx beat feedback research

- MIDI controller mapping, beat feedback, optional tempo sync and basic audio quality checks.
